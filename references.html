References and Resources

The resources below provide reliable information about cybersecurity, online safety, and web security practices. They can be used to explore the topics covered in this project in greater detail.

Cybersecurity and Infrastructure Security Agency (CISA)

CISA provides guidance on phishing, passwords, software updates, and protecting organizations and individuals from cyber threats.

Visit the CISA website

National Institute of Standards and Technology (NIST)

NIST publishes cybersecurity frameworks, guidance, and standards that help organizations manage security risks.

Visit NIST Cybersecurity

Federal Trade Commission (FTC)

The FTC shares consumer advice about recognizing scams and protecting personal information online.

Visit FTC online security resources

Open Worldwide Application Security Project (OWASP)

OWASP provides resources about web application security risks and methods developers can use to build safer websites.

Visit OWASP

Google Safe Browsing

Google Safe Browsing provides information about web risks and technology designed to warn users about certain dangerous websites.

Visit Google Safe Browsing

Using Sources Responsibly

Cybersecurity guidance changes as threats and technologies evolve. Readers should consult the original organizations for current recommendations and verify information before applying it to important systems.
